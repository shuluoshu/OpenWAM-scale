# Sparse Stage1 / Single-node 32 GPU Implementation Plan

> **For agentic workers:** Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** Add the user-selected 3 FPS, all-source, single-node 32 GPU version without replacing the existing 15 FPS / 8 GPU preset.

**Architecture:** Make finite-index sampling rate an explicit Stage1 config value (default 15). Validate it in preparation, check, training and resume. Reuse the existing world-size-agnostic DDP loop and single-node torchrun launch for both stages. Add a separate 32 GPU pipeline preset and output directory.

**Tech Stack:** Python, YAML/OmegaConf, SQLite finite index, PyTorch DDP/torchrun, pytest.

## Global Constraints

- All retained source directories and original task/subtask endpoint definitions stay selected; wipe_table remains excluded as already authorized.

- A complete Stage1 pass triggers frozen Stage2 as before; evaluation every 500 optimizer updates appends its own output.
- No production training launch or claim of actual 32 GPU speed/memory verification.
